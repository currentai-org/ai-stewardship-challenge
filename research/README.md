# Bibliography

Sources from the challenge's literature review: published research, project and platform
policies, standards, tools, and posts on portable contributor trust, onboarding and succession,
and governance of AI agents in open source.

This is a snapshot of the `sovereigntech.prior_art.sources` table on Artio, taken 2026-11-22
(sources researched 2026-11-15). The live
[literature review](https://www.artio.so/sovereigntech/pages/literature-review) has a summary,
key findings, and lessons for each source, plus a synthesis per track.

**Tracks:** A = portable contributor trust, B = onboarding and succession, C = agent governance.
**Evidence:** _measured_ = a number from data; _stated_ = a policy or claim; _design-only_ = a
specification or proposal.

To suggest an addition, open a
[share a resource](https://github.com/currentai-org/ai-stewardship-challenge/issues/new?template=share-a-resource.yml)
issue.
